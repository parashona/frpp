PDF Content Generation Prompt
Create the complete, ready-to-use text content for a simple PDF that will be delivered to someone who has already purchased an AI Prompt.

The PDF is not a sales page, promotional document, ebook, tutorial, or detailed explanation of the product.

The buyer already knows what the Prompt is, why they bought it, and what problem it is intended to help with.

The sole purpose of this PDF is to deliver the purchased Prompt clearly and make it immediately usable.

INPUTS

Prompt Name:
[Write the exact name of the Prompt here]

Prompt:
[Paste the complete Prompt here exactly as it should be delivered to the buyer]

Optional Short Description:
[Add a one-sentence description only if useful]

Create the PDF content using this simple structure:

1. THANK YOU

Begin with a short, warm and direct paragraph thanking the buyer for purchasing the Prompt and for trusting the author.

Keep it to 1–2 sentences.

Do not make it promotional, emotional, exaggerated, or sales-oriented.

The paragraph should simply acknowledge the purchase and the buyer’s trust in the author.

2. PROMPT NAME

Use the exact Prompt Name provided in the input.

3. SHORT INTRODUCTION

Write 1–2 short sentences explaining what the buyer is receiving.

Do not sell, persuade, create urgency, or repeat the product's sales pitch.

4. HOW TO USE

Give only the minimum practical instructions needed to use the Prompt.

Normally use 3–4 simple steps:

Step 1 — Read the Prompt and identify any [bracketed] sections that require your information.

Step 2 — Replace only the required placeholder information with your own details.

Step 3 — Copy the complete Prompt.

Step 4 — Paste it into ChatGPT and follow the Prompt's instructions.

Adapt these steps when the Prompt itself requires a different input or workflow.

5. BEFORE YOU USE IT

Mention only the information or preparation the buyer actually needs before using the Prompt.

Do not add unnecessary advice.

If no preparation is needed, omit this section.

6. THE PROMPT

Present the complete Prompt exactly as provided.

Do not rewrite it.
Do not improve it.
Do not shorten it.
Do not add instructions inside it.
Do not change its wording, structure, placeholders, or sequence.

The Prompt must remain the central and most prominent part of the PDF.

7. IMPORTANT NOTE

Add only essential usage notes that are directly relevant to using this Prompt correctly.

Do not repeat information already obvious from the Prompt.

If the Prompt involves AI-generated analysis, recommendations, assumptions, inference, or interpretation, include a brief appropriate note that the output should be treated as AI-generated guidance rather than guaranteed fact or result, only when relevant.

8. QUICK START

End with a very short practical instruction telling the buyer what to do next.

For example:

“Copy the Prompt above, paste it into ChatGPT, provide the requested information, and run it.”

Do not add a sales pitch, call to action for another product, testimonial, marketing message, or promotional content unless explicitly provided in the input.

GENERAL RULES

- Keep the PDF compact and practical.
- Aim for approximately 1–2 pages of content.
- The Prompt itself should receive the most space and attention.
- Use short headings, short paragraphs, numbered steps, and simple language.
- Do not create an elaborate introduction.
- Do not explain the underlying framework unless the buyer needs that explanation to use the Prompt.
- Do not create an example output unless explicitly requested.
- Do not create FAQs unless explicitly requested.
- Do not add benefits, features, claims, testimonials, guarantees, or marketing copy unless explicitly provided.
- Do not turn the PDF into a sales document.
- Do not assume anything about the Prompt that is not supported by the supplied Prompt or inputs.
- Preserve the exact terminology used in the supplied Prompt.
- If a section is unnecessary for the particular Prompt, omit it rather than filling the PDF with generic content.
- The PDF should feel like a clean, useful delivery document for a purchased Prompt, not a product brochure.

LANGUAGE AND STYLE

Write in Bengali (India) unless another language is specified.

Use natural, modern Kolkata-style Bengali.

Always address the reader as “আপনি”.
Never use “তুমি” or “তুই”.

Common English terms such as AI, Prompt, ChatGPT, Input, Output, Skill, Problem, Value, Buyer, etc. may be retained where they make the instructions clearer and more natural.

FINAL OUTPUT

Return only the complete PDF-ready text content.

Do not create the PDF file.
Do not provide design instructions.
Do not provide HTML.
Do not provide markdown formatting instructions.

The final content should be ready to paste directly into Google Docs and export as a PDF.
